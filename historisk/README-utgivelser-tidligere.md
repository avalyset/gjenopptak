# Historiske filer — les dette først

Filene i `utgivelser-tidligere.zip` er release notes og portstatus for tidligere versjoner av depositumet. De er
ikke rettet siden de ble skrevet. **Status i dem er status den dagen de ble skrevet.** Gjeldende status står i
`README.md` og `ZENODO.md` i depositumet; `ZENODO.md` fører hver versjon med DOI og dato.

*These files are release notes and gate reports for earlier versions, kept as written. Any status they state is the
status on the day they were written; the current status is in `README.md` and `ZENODO.md`.*
